Quick Start
# Install from source
pip install -e .

# Discover skills
pullnexus list
pullnexus search debugging

# Pull one locally
pullnexus pull python-advanced-debugging

Use pulled skill folders for context loading, prompt packs, or fine-tuning datasets.

Project Direction

PullNexus is building the missing intelligence layer for local-first AI: discoverable, pullable, remixable skills with open governance and no paywalls.

  • JSONL-first skill format
  • CLI for search, pull, submit, list
  • MCP-compatible patterns
  • Community skill curation loop
