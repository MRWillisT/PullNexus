Project Direction

PullNexus is building the missing intelligence layer for local-first AI: discoverable, pullable, remixable skills with open governance and no paywalls.

  • JSONL-first skill format
  • CLI for search, pull, submit, list
  • MCP-compatible patterns
  • Community skill curation loop

MCP Assistant Mode

Any AI assistant connected to the PullNexus MCP server can use the live registry as part of the conversation instead of guessing from generic background knowledge.

  • Search the registry mid-conversation for relevant skills, playbooks, datasets, or tools.
  • Recommend concrete resources based on the user's stack, failure mode, or goal.
  • Pull installable resources locally without leaving the chat flow.
  • Submit compatibility feedback after a workflow succeeds or fails.
1. Search Find live resources instead of answering from memory alone.
2. Recommend Rank useful options against the actual problem being described.
3. Install Pull the chosen resource into a local folder for immediate use.
4. Report Back Append compatibility feedback so the registry gets smarter over time.
Try This Prompt
I’m building a fully local RAG pipeline for PDFs with Ollama. Retrieval quality is bad, chunking feels wrong, and I want something concrete I can inspect or install. What should I use?
Without PullNexus

"You could try LangChain, Chroma, or LlamaIndex. Here are some general RAG tips for chunk size and embeddings."

Helpful, but generic. No live registry search, no concrete PullNexus resources, no install step.

With PullNexus MCP

"I found local-rag-starter-pack, a playbook for local RAG pipelines covering ingestion, chunking, embeddings, vector DB setup, retrieval, reranking, and eval."

"I also found rag-eval-baseline for retrieval precision/recall and answer faithfulness. If you want, I can pull local-rag-starter-pack into ./pullnexus-skills right now."

Good demo questions mention a real stack, a clear failure mode, and a concrete goal. RAG setup, debugging, agent workflows, or fine-tuning all work well for before/after comparisons.
