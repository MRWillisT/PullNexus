# Community Resources

A curated set of open repositories that can amplify local AI and agent workflows.

## High-Signal Repos

1. Claude Mem  
   https://github.com/thedotmack/claude-mem  
   Persistent memory across sessions.

2. UI UX Pro Max  
   https://github.com/nextlevelbuilder/ui-ux-pro-max-skill  
   UI/UX style packs and guidance.

3. n8n-MCP  
   https://github.com/czlonkowski/n8n-mcp  
   n8n integrations through MCP.

4. LightRAG  
   https://github.com/hkuds/lightrag  
   Graph plus vector retrieval patterns.

5. Everything Claude Code  
   https://github.com/affaan-m/everything-claude-code  
   Broad collection of Claude Code workflows.

6. Awesome Claude Code  
   https://github.com/hesreallyhim/awesome-claude-code  
   Curated list of tools and patterns.

7. Superpowers  
   https://github.com/obra/superpowers  
   Structured thinking prompts and routines.

8. Claude Code Ultimate Guide  
   https://github.com/FlorianBruniaux/claude-code-ultimate-guide  
   Long-form docs and templates.

9. Antigravity Awesome Skills  
   https://github.com/sickn33/antigravity-awesome-skills  
   Large skill collection.

10. Claude Agent Blueprints  
    https://github.com/danielrosehill/Claude-Code-Repos-Index  
    Agent workspace templates and examples.

11. VoiceMode MCP  
    https://github.com/mikecbaley/voicemode-mcp  
    Voice interaction layer for agent workflows.

12. Awesome Claude Plugins  
    https://github.com/quemsah/awesome-claude-plugins  
    Large plugin and repo index.

13. KronosA  
   https://github.com/shiyu-coder/KronosA  
   Forecasting model repo used as reference for PullNexus Kronos integration skill.

## Notes

- This list is a starting point for inspiration and interoperability ideas.
- Inclusion is not an endorsement; evaluate security and maintenance before adoption.
