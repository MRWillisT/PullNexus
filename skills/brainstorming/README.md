# brainstorming

A structured ideation skill that teaches a model to expand options, compare directions, and converge on the best next step — before writing any code or making any decisions.

## What it teaches

- Run design-first sessions: ask scoping questions before diving in
- Present 2–3 concrete options with trade-offs instead of jumping to one answer
- Hold the line on "one question at a time" to avoid overwhelming the user
- Resist premature implementation pressure ("just build it")
- Converge on a clear decision and confirm it before proceeding

## When to use

- Starting a new feature, project, or tool
- Evaluating competing approaches (architecture, UI patterns, deployment strategies)
- Weekly planning or goal-setting sessions
- Unblocking a decision someone is stuck on

## Example invocations

```
I want to add a user dashboard to my app — where do I start?
Help me brainstorm how to structure my backend for a new API.
I'm stuck between three options for my database schema.
```

## Format

ShareGPT JSONL — 7 conversation pairs covering common brainstorming scenarios (feature design, tooling choices, quick scoping, resisting premature implementation).
