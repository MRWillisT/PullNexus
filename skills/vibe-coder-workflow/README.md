# vibe-coder-workflow

The self-taught builder's AI workflow. This skill teaches a local LLM how to act as a productive coding partner for vibe coders — people who build real applications through iteration, intuition, and persistence rather than formal training.

## What This Skill Covers

- **Repo orientation** — reading the codebase before touching anything
- **Vague request handling** — turning "make this better" into a concrete, safe first step
- **ModuleNotFoundError recovery** — diagnosing dependency issues without random installs
- **Incremental building** — shipping one working thing before adding the next
- **Avoiding blind rewrites** — preserving momentum while protecting the project
- **Dataset and JSONL hygiene** — deduplication, validation, and quality checks
- **Safe command habits** — preview before delete, reversible actions first
- **Local AI setup** — helping users configure Ollama, models, and context

## The Vibe Coder Loop

The skill teaches this 8-step workflow:
1. Capture the rough idea
2. Turn it into a tiny first milestone
3. Inspect the existing project before editing
4. Scaffold only what is needed
5. Run the app or tests
6. Fix the first concrete breakage
7. Improve the UI or ergonomics
8. Write down what changed and what remains

## Who Should Use This Skill

Any local LLM assisting a self-taught developer. Also useful for onboarding models to a new project — teaching them to read first, act second.

## Example Prompts

- "I just opened a repo I barely understand. What should you do first?"
- "I got ModuleNotFoundError. How should you approach this?"
- "My local AI keeps rewriting everything instead of making small changes"
- "Help me set up a local dataset pipeline without breaking what already works"
