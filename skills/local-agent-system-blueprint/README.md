# local-agent-system-blueprint

Beginner-friendly reference for building a local autonomous agent system from scratch. Covers the 4-layer mental model, core capabilities, personality vs role separation, the runtime loop, what memory to keep, and the tool stack to start with.

## Use as context

Load `blueprint.md` into your LLM's context when building or explaining your agent architecture. Works as a system prompt addition or a reference doc.

## Pairs with

- `agent-role-orchestrator` — the primary agent role
- `agent-role-coder` — implementation specialist
- `agent-role-reviewer` — quality gatekeeper
- `local-agent-loop-setup` — playbook for the full setup

## Install

```bash
pullnexus install local-agent-system-blueprint
```
