# code-refactoring

Practical refactoring guidance for real-world Python projects where you need safer cleanup, better readability, and maintainable structure without rewriting everything.

## What This Skill Covers

- Refactoring large files into smaller units safely
- Renaming unclear variables and functions without behavior changes
- Removing duplication and dead code with low regression risk
- Creating step-by-step refactor plans for vibe-coder workflows
- Writing focused tests before and after structural changes

## Who Should Use This Skill

Developers who inherited messy code, rapid prototypes that need cleanup, or AI-generated code that works but is hard to maintain.

## Usage

```bash
pullnexus pull code-refactoring
```

Use `examples.jsonl` for behavior tuning and `eval.jsonl` for quality checks.
