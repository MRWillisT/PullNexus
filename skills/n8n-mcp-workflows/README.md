# n8n-mcp-workflows

A skill for teaching local LLMs how to design and maintain n8n automations through MCP-oriented workflows.

## What This Skill Covers

- Translating user intent into n8n node graphs
- Building robust trigger-action pipelines
- Validation, retries, and failure-path handling
- Secret handling and environment-safe deployment patterns
- Iterating on workflows with test data and staged rollouts

## Why It Matters

n8n's MCP momentum shows major tools are becoming LLM-editable. PullNexus can be the place where practical patterns are shared and improved.

## Usage

```bash
pullnexus pull n8n-mcp-workflows
```
