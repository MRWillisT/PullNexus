# crypto-trading-bot

A practical skill for building safer and more realistic crypto trading systems, from strategy logic to execution details that often break live performance.

## What This Skill Covers

- Market cycle and regime detection
- Order types, slippage, and liquidity-aware sizing
- Backtesting discipline and overfitting prevention
- Position sizing and risk guardrails
- On-chain confirmation metrics for higher-level bias

## Who Should Use This Skill

Anyone building or tuning local AI assistants for trading research, bot development, and strategy diagnostics.

## Usage

```bash
pullnexus pull crypto-trading-bot
```
