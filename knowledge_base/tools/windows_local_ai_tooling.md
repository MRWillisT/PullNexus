# Windows Local AI Tooling

## Core Commands

- `py -3`: run Python when `python` is not on PATH.
- `rg`: fast text and file search.
- `nvidia-smi`: confirm NVIDIA GPU driver and VRAM visibility.
- `ollama run <model>`: run a local model.
- `ollama create <name>`: create an Ollama model from a Modelfile.

## Safety Habits

- Preview file lists before cleanup.
- Avoid recursive delete unless the target path is confirmed.
- Prefer PowerShell-native commands on Windows.
- Keep raw exports separate from cleaned training data.
