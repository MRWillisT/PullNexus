# Knowledge Base

This directory stores exported chats, cleaned corpora, project context, and agent system documentation.

## Folders

- `chats_raw/`: immutable original exports
- `chats_clean/`: normalized/cleaned data for training or retrieval
- `projects/`: project-specific context and decisions
- `agent_system/`: orchestration, memory, prompts, and runtime policies
- `tools/`: tool docs, command policies, and usage references
- `skills/`: reusable role-specific workflows
- `notes_useful_info/`: ad hoc insights and research notes
- `index/`: catalogs, manifests, and retrieval indexes

## Seed Content

The knowledge base now includes starter content in `agent_system/`, `notes_useful_info/`, `projects/`, `skills/`, `tools/`, and `index/`. The `chats_raw/` and `chats_clean/` folders are still reserved for ingested chat exports and cleaned retrieval-ready chat notes.
